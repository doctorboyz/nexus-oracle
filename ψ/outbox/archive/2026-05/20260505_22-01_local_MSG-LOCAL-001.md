synapse เป็น tool ในเครื่อง ที่ทำหน้าที่ นำข้อมูลความรู้มาสังเคราะห์ และสร้างความเชื่อมโยง ใน 3 ระดับ คือ file , vector , และ database ทำงานอยู่เบื้องหลัง ตามเวลา schedule โดยมี LLM และ embbed model (ควรเป็น local model เพื่อความปลอดภัย)ทำหน้าที่อ่านและเก็บข้อมูล โดยเริ่มจาก init ตรวจทั้งหมดสร้าง ฐานข้อมูลครั้งแรก จากนั้น ตรวจไฟล์ใหม่ตามเวลา มีคำสั่งเหมือน /defrag + /detox ที่จัดระเบียบ ตรวจหา conflict และ mismatch เพื่อปรับปรุง มี test interface ให้ลองถามเพื่อตรวจสอบ retrieval ทำงานภายในเครื่องเท่านั้น ไม่ออก network เด็ดขาด และไม่แก้ไข code ของ project อื่น แค่รวบรวมความรู้เฉยๆ
